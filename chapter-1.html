✅ Must-know rules and formulas

1.1 Integers and Absolute Value

  • Integers are …, −3, −2, −1, 0, 1, 2, 3, …
  • Absolute value |a| is the distance from 0, so it is never negative: |−7| = 7.
  • On a number line, numbers increase to the right; −2 > −9.

1.2 Adding Integers

  • Same signs: add absolute values, keep the sign.
  • Different signs: subtract absolute values, keep the sign of the larger absolute value.
  • A number plus its opposite is 0.

1.3 Subtracting Integers

  • Subtracting is adding the opposite: a − b = a + (−b).
  • a − (−b) = a + b.

1.4 Multiplying Integers

  • Same signs → positive product; different signs → negative product.
  • Even number of negative factors → positive; odd → negative.
  • (−2)² = 4 but −2² = −4.

1.5 Dividing Integers

  • Same signs → positive quotient; different signs → negative quotient.
  • 0 ÷ a nonzero number = 0; division by 0 is undefined.
  • Mean of integers: add them, then divide by how many.

⚠️ Common mistakes and how to avoid them
  • Mistake: Thinking −8 > −3 because 8 > 3.
    Avoid it: Negatives farther from 0 are smaller; use a number line.
  • Mistake: Writing 4 − (−6) = −2.
    Avoid it: Change to adding the opposite: 4 + 6 = 10.
  • Mistake: Wrong sign on products with several negatives.
    Avoid it: Count the negative factors: even → +, odd → −.
  • Mistake: Giving a negative absolute value.
    Avoid it: Absolute value is a distance, so it is 0 or positive.
  • Mistake: Mixing up "−5 + 3" with "5 − 3".
    Avoid it: Say it with money: you owe $5 and get $3, so you still owe $2: −2.

💯 Test-taking tips for a perfect score
  • Show every step. Write each step on its own line so you (and your teacher) can find mistakes, and so you can earn partial credit.
  • Check the signs. Before you finish a problem, ask: should the answer be positive or negative? Circle the sign.
  • Estimate first. Round the numbers and get a rough answer. If your final answer is far from your estimate, redo it.
  • Reread word problems. Underline what the question asks for and the important numbers. Make sure you answer the actual question.
  • Check units and form. Include units (feet, $, square inches) and give the answer in the form asked (simplest form, decimal, percent).
  • Do the easy ones first. Skip a hard problem, mark it, and come back. Don’t leave anything blank.
  • Go back and verify. Use extra time to plug answers back in, redo calculations a different way, and check that every question is answered.
  • Stay calm. If you get stuck, take a deep breath, write what you know, and try a small example.

1.1 Integers and Absolute Value

💡 The big idea

Integers are the whole numbers, their opposites, and zero: …, −3, −2, −1, 0, 1, 2, 3, … On a number line, numbers to the right are bigger, so −2 is greater than −9. The absolute value of a number is its distance from 0, so it is never negative. We write it with bars: |−7| = 7 and |7| = 7. Pairs like 5 and −5, which sit equally far from 0 but on different sides, are called opposites.

📝 Key vocabulary

  • integer: a whole number, its opposite, or zero
  • absolute value: distance from 0 on a number line
  • opposites: a pair of numbers equally far from 0, one on each side

✏️ Worked example

Problem: Find |−12| − |4|.

  1. |−12| = 12 because −12 is 12 units from 0.
  2. |4| = 4.
  3. 12 − 4 = 8

Answer: 8

    1.2 Adding Integers

    💡 The big idea

    When you add integers with the same sign, add their absolute values and keep the sign: −4 + (−6) = −10. When the signs are different, subtract the smaller absolute value from the larger one and keep the sign of the number with the larger absolute value. A number plus its opposite is 0; these are called additive inverses. You can picture adding a positive number as moving right on a number line and adding a negative number as moving left.

    📝 Key vocabulary

    • additive inverse: the opposite of a number; together they add to 0
    • sum: the answer to an addition problem

    ✏️ Worked example

    Problem: Find −9 + 14.

    1. Different signs, so subtract absolute values: 14 − 9 = 5.
    2. 14 has the larger absolute value and it is positive.
    3. So −9 + 14 = 5.

    Answer: 5

      1.3 Subtracting Integers

      💡 The big idea

      To subtract an integer, add its opposite: a − b = a + (−b). That means 3 − 8 becomes 3 + (−8) = −5, and 4 − (−6) becomes 4 + 6 = 10. Subtracting a negative number makes the answer bigger, which surprises a lot of people at first! Subtraction also tells you the distance between two numbers, like the difference between two elevations.

      📝 Key vocabulary

      • opposite: the number with the same absolute value but the other sign
      • difference: the answer to a subtraction problem

      ✏️ Worked example

      Problem: Find −5 − (−12).

      1. Add the opposite of −12, which is 12.
      2. −5 + 12 = 7

      Answer: 7

        1.4 Multiplying Integers

        💡 The big idea

        When you multiply integers, first multiply the absolute values, then decide the sign. If the two numbers have the same sign, the product is positive; if they have different signs, the product is negative. For longer problems, count the negative factors: an even number of them gives a positive answer and an odd number gives a negative answer. Watch exponents too: (−2)² = 4, but −2² means −(2²) = −4.

        📝 Key vocabulary

        • product: the answer to a multiplication problem
        • factor: a number being multiplied

        ✏️ Worked example

        Problem: Find −3 × 4 × (−5).

        1. 3 × 4 × 5 = 60.
        2. There are two negative factors (an even number), so the answer is positive.
        3. Answer: 60

        Answer: 60

          1.5 Dividing Integers

          💡 The big idea

          Dividing integers uses the same sign rules as multiplying. Divide the absolute values, then make the answer positive if the signs are the same and negative if they are different. You can never divide by zero, but 0 divided by any nonzero number is 0. Division is useful for finding a mean (average) change, like the average daily temperature change over a week.

          📝 Key vocabulary

          • quotient: the answer to a division problem
          • mean: the sum of the values divided by how many values there are

          ✏️ Worked example

          Problem: Find −56 ÷ 8.

          1. 56 ÷ 8 = 7.
          2. Different signs, so the quotient is negative.
          3. Answer: −7

          Answer: −7
