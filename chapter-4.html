4.1 Writing and Graphing Inequalities

💡 The big idea

An inequality compares two expressions using <, >, ≤ (at most), or ≥ (at least). A solution of an inequality is any value that makes it true, and there are usually infinitely many. To graph one on a number line, use an open circle for < or > (the number is not included) and a closed circle for ≤ or ≥ (the number is included), then shade the direction of the solutions. Key phrases like "no more than" mean ≤ and "at least" means ≥.

📝 Key vocabulary

  • inequality: a statement that uses <, >, ≤, or ≥
  • solution set: all the values that make the inequality true
  • graph of an inequality: a number line showing all the solutions

✏️ Worked example

Problem: Write an inequality: "You must be at least 48 inches tall to ride." Is 47.5 inches a solution?

  1. "At least" means ≥, so h ≥ 48.
  2. Check 47.5: is 47.5 ≥ 48? No.

Answer: h ≥ 48; 47.5 is not a solution.

🎯 Practice

  1. Write an inequality: "A number x is less than −3."

    Answer: x < −3

  2. Write an inequality: "You can spend no more than $20." Use d for dollars.

    Answer: d ≤ 20

  3. Is −5 a solution of n + 2 > −4?

    Answer: Yes. −5 + 2 = −3, and −3 > −4 is true.

  4. Which of these are solutions of 3x ≤ 12: x = 2, x = 4, x = 5?

    Answer: x = 2 and x = 4 (5 is not, since 15 > 12)

  5. Describe the graph of y > 1.5.

    Answer: An open circle at 1.5 with shading to the right.

4.2 Solving Inequalities Using Addition or Subtraction

💡 The big idea

You solve inequalities with addition or subtraction the same way you solve equations. Adding or subtracting the same number on both sides keeps the inequality true, so the inequality sign stays the same. After solving, graph the solution and test a value from the shaded part to make sure it works. For example, x − 4 > 2 becomes x > 6.

📝 Key vocabulary

  • Addition Property of Inequality: adding the same number to both sides keeps it true
  • Subtraction Property of Inequality: subtracting the same number from both sides keeps it true

✏️ Worked example

Problem: Solve y + 7 ≤ 3.

  1. Subtract 7 from both sides: y ≤ 3 − 7.
  2. y ≤ −4
  3. Test y = −5: −5 + 7 = 2 ≤ 3 ✓

Answer: y ≤ −4

🎯 Practice

  1. Solve x − 5 < 9.

    Answer: x < 14

  2. Solve n + 6 ≥ −2.

    Answer: n ≥ −8

  3. Solve −3 > k − 1.5.

    Answer: k < −1.5

  4. Solve w + 3/4 ≤ 1/2.

    Answer: w ≤ −1/4

  5. Your backpack can hold at most 15 pounds and already has 8.5 pounds in it. Solve p + 8.5 ≤ 15.

    Answer: p ≤ 6.5 pounds

4.3 Solving Inequalities Using Multiplication or Division

💡 The big idea

Multiplying or dividing both sides of an inequality by a positive number keeps the sign the same. But if the number you multiply or divide by is negative, the inequality symbol has to flip direction (we say you reverse the inequality sign). For example, −2x < 6 becomes x > −3 after dividing by −2. A quick test with a number from your answer helps you catch a sign you forgot to flip.

📝 Key vocabulary

  • reverse the inequality symbol: change < to > (or ≤ to ≥) and vice versa
  • Multiplication/Division Properties of Inequality: rules for keeping an inequality true when you multiply or divide

✏️ Worked example

Problem: Solve −2x < 6.

  1. Divide both sides by −2 and reverse the sign.
  2. x > −3
  3. Test x = 0: −2(0) = 0 < 6 ✓

Answer: x > −3

🎯 Practice

  1. Solve 4x ≥ 28.

    Answer: x ≥ 7

  2. Solve −5n > 35.

    Answer: n < −7 (flip the sign!)

  3. Solve y ÷ 3 ≤ −2.

    Answer: y ≤ −6

  4. Solve k ÷ (−4) < 1.5.

    Answer: k > −6

  5. Tickets cost $6.50 each and you have $40. Solve 6.5t ≤ 40. What is the most tickets you can buy?

    Answer: t ≤ about 6.15, so at most 6 tickets

4.4 Solving Two-Step Inequalities

💡 The big idea

A two-step inequality, like 3x − 4 > 11, is solved just like a two-step equation. Undo addition or subtraction first, then multiplication or division. The one extra rule: if you multiply or divide by a negative number, flip the inequality sign. Finish by graphing the solution and testing a value.

📝 Key vocabulary

  • two-step inequality: an inequality that takes two inverse operations to solve
  • test value: a number you plug in to check your solution

✏️ Worked example

Problem: Solve 3x − 4 > 11.

  1. Add 4 to both sides: 3x > 15.
  2. Divide by 3: x > 5.
  3. Test x = 6: 3(6) − 4 = 14 > 11 ✓

Answer: x > 5

🎯 Practice

  1. Solve 2x + 5 ≤ 17.

    Answer: x ≤ 6

  2. Solve −3n + 1 > 13.

    Answer: n < −4

  3. Solve y/2 − 3 ≥ −1.

    Answer: y ≥ 4

  4. Solve 6 − 4k < −10.

    Answer: k > 4

  5. You have $50 and save $15 each week. Solve 50 + 15w ≥ 200 to find when you will have at least $200.

    Answer: w ≥ 10 weeks
