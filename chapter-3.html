3.1 Algebraic Expressions

💡 The big idea

An algebraic expression uses numbers, variables, and operations, like 4x − 3 + 2x. Each part separated by + or − is a term, and the number in front of a variable is its coefficient. Like terms share exactly the same variable part (same letters with the same exponents), so 4x and 2x are like terms, but 4x and 4 are not. To simplify an expression, combine like terms: 4x − 3 + 2x = 6x − 3.

📝 Key vocabulary

  • term: a part of an expression separated by + or −
  • coefficient: the number multiplied by a variable
  • like terms: terms with the same variable parts
  • simplest form: an expression with no like terms left to combine

✏️ Worked example

Problem: Simplify 7y + 5 − 3y − 8.

  1. Group like terms: (7y − 3y) + (5 − 8).
  2. = 4y + (−3)
  3. = 4y − 3

Answer: 4y − 3

🎯 Practice

  1. Simplify 5a + 2b − a + 9. Which terms were like terms?

    Answer: 4a + 2b + 9 (5a and −a were like terms)

  2. Simplify 3x + 8x − 4.

    Answer: 11x − 4

  3. Simplify 6 − 2n + 5n − 10.

    Answer: 3n − 4

  4. Simplify 1.5k − 0.75k + 2.

    Answer: 0.75k + 2

  5. Evaluate 4x − 3 + 2x when x = −2.

    Answer: −15 (simplify to 6x − 3, then 6(−2) − 3 = −15)

3.2 Adding and Subtracting Linear Expressions

💡 The big idea

A linear expression has variables only to the first power, like 3x + 5. To add linear expressions, combine the like terms: (3x + 5) + (2x − 1) = 5x + 4. To subtract, add the opposite of every term in the second expression, so (3x + 5) − (2x − 1) = 3x + 5 − 2x + 1 = x + 6. Forgetting to change the sign of every term in the second expression is the most common mistake.

📝 Key vocabulary

  • linear expression: an expression whose variables have exponent 1
  • opposite of an expression: change the sign of every term

✏️ Worked example

Problem: Find (4y − 7) − (−2y + 3).

  1. Add the opposite: 4y − 7 + 2y − 3.
  2. Combine like terms: 6y − 10.

Answer: 6y − 10

🎯 Practice

  1. Find (2x + 6) + (5x − 9).

    Answer: 7x − 3

  2. Find (−3m + 4) + (m − 10).

    Answer: −2m − 6

  3. Find (8a − 1) − (3a + 4).

    Answer: 5a − 5

  4. Find (−x − 2) − (−4x − 7).

    Answer: 3x + 5

  5. One rectangle side is (2w + 3) cm and another is (w − 1) cm. Write the perimeter 2(2w + 3) + 2(w − 1) in simplest form.

    Answer: 6w + 4 cm

Extension 3.2 Factoring Expressions

💡 The big idea

Factoring an expression means writing it as a product, which is the Distributive Property in reverse. First find the greatest common factor (GCF) of the terms, then pull it out in front of parentheses. For example, 12x + 18 = 6(2x + 3) because 6 is the GCF of 12 and 18. You can check your work by distributing to see if you get the original expression back.

📝 Key vocabulary

  • factor (verb): to write as a product
  • greatest common factor (GCF): the biggest number that divides every term
  • Distributive Property: a(b + c) = ab + ac

✏️ Worked example

Problem: Factor 15n − 25.

  1. The GCF of 15 and 25 is 5.
  2. 15n ÷ 5 = 3n and 25 ÷ 5 = 5.
  3. So 15n − 25 = 5(3n − 5).

Answer: 5(3n − 5)

🎯 Practice

  1. Factor 8x + 12 using the GCF.

    Answer: 4(2x + 3)

  2. Factor 21y − 14.

    Answer: 7(3y − 2)

  3. Factor 30 + 45k.

    Answer: 15(2 + 3k)

  4. Factor out 1/2 from 1/2x − 3.

    Answer: 1/2(x − 6)

  5. Factor −6 out of −6p + 24.

    Answer: −6(p − 4)

3.3 Solving Equations Using Addition or Subtraction

💡 The big idea

An equation says two expressions are equal, and a solution is a value that makes it true. To solve, get the variable alone using inverse operations: addition undoes subtraction and subtraction undoes addition. Whatever you do to one side, you must do to the other side to keep it balanced. Always check by substituting your answer back into the original equation.

📝 Key vocabulary

  • equation: a statement that two expressions are equal
  • solution: a value that makes the equation true
  • inverse operations: operations that undo each other

✏️ Worked example

Problem: Solve x − 4.5 = −2.

  1. Add 4.5 to both sides: x = −2 + 4.5.
  2. x = 2.5
  3. Check: 2.5 − 4.5 = −2 ✓

Answer: x = 2.5

🎯 Practice

  1. Solve x + 9 = 4.

    Answer: x = −5

  2. Solve y − 7 = −12.

    Answer: y = −5

  3. Solve −3 = n + 8.

    Answer: n = −11

  4. Solve k + 2/3 = 1/6.

    Answer: k = −1/2

  5. After spending $14.75, you have $22.40 left. Solve m − 14.75 = 22.40 to find how much you started with.

    Answer: $37.15

3.4 Solving Equations Using Multiplication or Division

💡 The big idea

When a variable is multiplied by a number, divide both sides by that number to undo it. When a variable is divided by a number, multiply both sides by that number. If the coefficient is a fraction, multiply both sides by its reciprocal. Keep both sides balanced and check your solution at the end.

📝 Key vocabulary

  • coefficient: the number multiplying the variable
  • reciprocal: the flipped fraction; 3/4 and 4/3 are reciprocals

✏️ Worked example

Problem: Solve −2/3 x = 8.

  1. Multiply both sides by −3/2, the reciprocal of −2/3.
  2. x = 8 × (−3/2) = −12
  3. Check: −2/3 × (−12) = 8 ✓

Answer: x = −12

🎯 Practice

  1. Solve 6x = −42.

    Answer: x = −7

  2. Solve n ÷ 5 = −3.

    Answer: n = −15

  3. Solve −0.4y = 2.8.

    Answer: y = −7

  4. Solve 3/4 w = 15.

    Answer: w = 20

  5. Eight friends split a bill equally and each pays $9.25. Solve b ÷ 8 = 9.25 to find the bill.

    Answer: $74

3.5 Solving Two-Step Equations

💡 The big idea

A two-step equation, like 3x + 5 = −10, needs two inverse operations to solve. Undo the addition or subtraction first, then undo the multiplication or division. If there are like terms on one side, combine them before you start. Checking your answer in the original equation catches small sign mistakes.

📝 Key vocabulary

  • two-step equation: an equation that takes two inverse operations to solve
  • like terms: terms with the same variable part

✏️ Worked example

Problem: Solve 3x + 5 = −10.

  1. Subtract 5 from both sides: 3x = −15.
  2. Divide both sides by 3: x = −5.
  3. Check: 3(−5) + 5 = −10 ✓

Answer: x = −5

🎯 Practice

  1. Solve 2x − 7 = 9.

    Answer: x = 8

  2. Solve −4n + 3 = 23.

    Answer: n = −5

  3. Solve y/3 + 6 = 2.

    Answer: y = −12

  4. Solve 5k + 2k − 4 = 17.

    Answer: k = 3

  5. A gym charges $25 to join plus $12 per month. You paid $121 total. Solve 12m + 25 = 121 for the number of months.

    Answer: 8 months
